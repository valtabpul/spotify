# Proyecto CRUD Spotify API

Este proyecto es un CRUD básico que interactúa con la API de Spotify. Está desarrollado en TypeScript, utilizando módulos ES, así como types e interfaces para una mejor estructura y tipado del código.

## Características principales
- CRUD (Crear, Leer, Actualizar, Eliminar) sobre recursos de Spotify.
- Código escrito en TypeScript.
- Uso de módulos para organizar la lógica.
- Definición de types e interfaces para garantizar un tipado estricto y seguro.

## Estructura del proyecto
- **TypeScript**: Todo el código fuente está escrito en TypeScript.
- **Módulos**: La lógica está separada en módulos para mayor mantenibilidad.
- **Types e Interfaces**: Se utilizan para definir la forma de los datos y las respuestas de la API.

## Instalación y uso
1. Clona el repositorio.
2. Instala las dependencias con `npm install`.
3. Compila el proyecto con `npm run build` o ejecuta en desarrollo con `npm run dev`.

## Notas
Por el momento, el proyecto está en una etapa inicial y se centra en la estructura base y el tipado.
